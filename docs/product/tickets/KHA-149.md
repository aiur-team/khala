## Contract and verification handoff

Consumes reviewed contract subpaths; defines only its owned module API. Dependencies supply reviewed contracts or actual wiring prerequisites; test each component against injected ports until its named integration owner supplies live composition. Keep unit tests adjacent to owned code.

At merge: own tests and affected contracts pass on current base, and `pnpm install --frozen-lockfile`, `pnpm lint`, `pnpm typecheck` and `pnpm test` all pass. Real proof belongs to the named integration/evidence owner in the repository layout; component tests are not deferred until then. A capability record may claim `support: "tested"` only when its `evidenceRef` names a document that exists under `docs/evidence/`.
