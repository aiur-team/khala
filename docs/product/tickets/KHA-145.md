## Outcome and acceptance

Records, from the installed Claude Code CLI, whether a Khala process the agent itself starts can deliver a released message into that agent existing session, and recommends exactly one route or none. Evidence, not an adapter.

## Amends or supersedes

Amends KHA-103. KHA-103 asked whether a third party could attach to a running session and answered no. This ticket asks the P15 question instead: can the agent own the process. It does not retract KHA-103; it scopes its conclusion. A negative result here is a valid completion and leaves KHA-149 fail-closed.
