**Tags:**
- **[VERBATIM]**: copy as is.
- **[VERIFIED]**: the DOM and behaviour come from the design JS (line cited).
- **[ADAPT]**: a deliberate change for the full-bleed product.
- **[DESIGN-BUG]**: §21 has the fix, and the parity audit uses the fixed behaviour.
- **[M2]**: needs data or features outside M1 (§22). The ticket must render it **disabled** or **omit** it, exactly as §22 says.

**Naming.** Keep the design's `kh-*` class names verbatim in the product stylesheet. Keep the design's unprefixed tokens (`--bg`, `--surface` and the rest), scoped to the app root. The design builds its DOM as strings with `data-kh-*` attributes. The product renders the same tags, classes and attributes from React components, and **must not** use `innerHTML`.

**Name line:**
- Only on `first` rows.
- The time is a **bare text node** after the tags. *v1 said a `<span>`; that was wrong.*

- Present on every non-viewer row.

## 12. Popovers, menus, segments, switches, buttons, tooltips, toast [VERIFIED `source:4405-4454`; CSS `source:613-678`]

### 12.1 Mechanics

- **One** `#kh-pop` per card, absolutely positioned **against `.kh-card`** (`khPopPlace`, `source:4431-4440`):
  - `left` = the anchor's left edge if the anchor is in the left half of the card, otherwise `anchor.right − popWidth`; clamped to `[8, cardW − popW − 8]`
  - `top` = `anchor.bottom + 6`; if that overflows, `anchor.top − popH − 6`; never less than 8
  - it re-places on window resize
- **Toggle:** the same anchor and kind closes it.
- **Close on:** an outside click, Escape, or opening another popover.
- The anchor gets `aria-expanded="true"`.
- `.kh-pop.menu` is used for the `leave`, `keb-*` and `mode` kinds.
- The first input autofocuses only with `(hover: hover)`.
