# U15 kitty and iTerm2 terminal wake

The adapters reuse U14 consent, idle, process identity, kernel foreground TTY ownership, styled empty-prompt, fixed-line, delayed submission and exact-insertion cleanup checks. Failed probes report reasons and never type. A draft before insertion skips without counting a failure.

kitty captures the window ID and listener, permits only Unix listeners, checks every reported foreground process against the captured agent ancestry, and obtains the TTY from `ps`. The cursor row comes from styled `get-text --extent screen --ansi --add-cursor`; the appended cursor metadata is parsed separately from screen text. No focus command or bracketed paste is used. The source contract was inspected in upstream [get_text.py](https://github.com/kovidgoyal/kitty/blob/master/kitty/rc/get_text.py) and [window.py](https://github.com/kovidgoyal/kitty/blob/master/kitty/window.py).

iTerm2 captures a validated UUID from `w0t0p0:<UUID>`. Its packaged Python helper obtains the session's screen and TTY, reconstructs faint cell styling for the shared prompt guard, and compares the exact approved cursor row, coordinates and TTY immediately before each send. It suppresses broadcast input and never activates a session. Cursor coordinates are absolute buffer coordinates: the row index subtracts the returned screen range start. API contracts were inspected in [Session](https://iterm2.com/python-api/session.html), [screen.py](https://github.com/gnachman/iTerm2/blob/master/api/library/python/iterm2/iterm2/screen.py), [PTYSession buffer response](https://github.com/gnachman/iTerm2/blob/master/sources/PTYSession/PTYSession.m), and [session variables](https://iterm2.com/documentation-variables.html).

Local validation covers capture, exact fake-binary argv, unavailable probes, TCP listener rejection, malformed session IDs, draft preservation, Python snapshot rechecks, styling and broadcast suppression, and hostile inbox bodies through the real wake ladder. Package smoke checks the helper after installation from the tarball. Agent typecheck, lint, build and the full agent suite pass.

kitty is not installed in this workspace; iTerm2 needs macOS. These results are transport/source-contract evidence, not live host acceptance or accepted R2 gaps.
